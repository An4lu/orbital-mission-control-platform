# Glossário

| Termo | Definição |
|---------|------------|
| Telemetria | Dados transmitidos pela nave |
| Payload | Carga útil transportada |
| Sensor Node | Nó sensor |
| Event Stream | Fluxo contínuo de eventos |
| Alert | Evento crítico |
| Critical Event | Ocorrência de alto risco |
| AI Engine | Motor de inteligência artificial |
| Fault Prediction | Predição de falhas |
| Mission Dashboard | Painel principal |
| Mission Module | Subsistema operacional |
| Incident | Registro de problema |
| Availability | Disponibilidade do sistema |
| Uptime | Tempo de funcionamento |
| Telecommand | Comando enviado à nave |
